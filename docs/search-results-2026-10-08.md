# 検索結果とスマホ詳細の改善（2026-10-08）

検索結果は施設写真（未登録・読み込み失敗時は既存カテゴリアイコン）、施設名、都道府県、市区町村を表示。選択行は背景・枠・選択中ラベル・aria-pressedで強調。検索結果総数を表示し、8件を超える場合は先頭8件のみの表示を明示。検索文字を消すボタンは入力・選択中施設をリセット。

写真の原典・撮影者・ライセンス・加工内容は検索結果の「写真の出典・利用条件」から確認可能。詳細画面にも従来の出典表示を維持。

手作業で照合済みの写真一覧をlib/place-photos.tsに移し、写真APIと検索サムネイルで共有。38件すべての写真・施設別名・カテゴリの対応を確認。サムネイル表示用の写真API呼び出しは追加しない。

スマホ（900px以下）で施設詳細を開くと検索パネルを高さ62px以内の検索入力1行へ縮小。詳細を閉じる、入力を変更する、または検索文字を消す操作で通常パネルを復元。詳細パネルの最大高さは58dvh（画面が低い場合は100dvh-170px以内）として地図を見る空間を残す。

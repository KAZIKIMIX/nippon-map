# PR26 改行と検索範囲案内の確認

## 問題と変更
PCの施設詳細で「マクセル アクアパーク品川」の川だけが次行に残る。text-wrap:balance単独ではアクアパークの途中で改行したため、word-break:keep-allを併用し、空白区切りのまとまりを優先する。パネル幅より長い無空白名はoverflow-wrap:anywhereで折り返す。文字サイズ・パネル幅・配色は変更しない。

## 検証範囲
現行CSSを使った固定HTMLをブラウザの1440px・390px iframeで比較。PCでは「マクセル」／「アクアパーク品川」に分かれ、390pxでは1行。検索範囲案内は両幅で表示。固定例の結果件数は実測ではない。地図・検索通信・選択解除・共有復元・実機スマホは未検証。簡略HTMLは実アプリの検索結果構造や選択状態を完全には再現しない。

## 反映条件
Draftを維持。実アプリでのPC・スマホ比較とユーザーの見た目の承認後にマージする。ロゴ・アイコン・基本レイアウトは維持。

## 追加確認
無空白の長い施設名、英数字の長い名称、320px・390px・PC、施設詳細を開いた状態での検索案内、検索解除、共有リンク復元。CSSが効かない旧ブラウザでも内容が欠落しないこと。

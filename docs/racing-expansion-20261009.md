# 競馬場・競輪場の掲載拡張（2026-10-09）

15地点を追加。競馬場は2→13地点、競輪場は2→6地点。

競馬場：JRAの未掲載9地点（札幌・函館・福島・新潟・中山・中京・京都・阪神・小倉）と地方競馬の船橋・浦和。既存東京を合わせJRAの10競馬場を掲載。地方競馬場は未網羅。

競輪場：大宮・西武園・静岡・小倉。全国未網羅。

名称・所在地・公式URLは施設公式情報と照合。座標13地点は国土地理院地名検索（公的代表点）。中京・船橋は駅との混同を避け、完全一致の施設名を選択。小倉競輪場は公式施設案内 https://www.kokurakeirin.com/guide/ でメディアドームとの同一性を確認。

大宮・西武園の座標は公式アクセスページの埋め込み地図の表示中心による概略位置。マーカー位置・入口位置と断定しない。個別の根拠URLと元座標はJSON内に記録。営業時間や料金は固定掲載せず公式リンクへ誘導。

承認済みのカテゴリ画像・ピン・既存アニメーションは維持。APIの掲載範囲説明と出典リンクを更新。権限やスキーマ変更なし。

重複チェック：既存施設の名称・所在地・公式URLで照合。追加SQLは既存URLまたは名称と自治体が一致する地点を再追加しない。自動採番IDは固定しない。
